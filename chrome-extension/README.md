# 😂 Extension Chrome - Joke Generator\n\nUne extension Google Chrome simple et élégante pour générer des blagues aléatoires en un clic!\n\n## 🎯 Caractéristiques\n\n✅ **Blagues Aléatoires** - Cliquez sur un bouton pour obtenir une nouvelle blague\n✅ **Copier** - Copiez facilement la blague au presse-papiers\n✅ **Partager** - Partagez directement sur Twitter\n✅ **Favoris** - Sauvegardez vos blagues préférées\n✅ **Mode Sombre** - Interface agréable avec mode sombre\n✅ **Stockage Local** - Vos favoris sont sauvegardés localement\n✅ **API Officielle** - Utilise l'Official Joke API\n\n## 📦 Installation\n\n### Méthode 1: Installation Manuelle (Mode Développeur)\n\n1. **Ouvrez Chrome** et allez à `chrome://extensions`\n2. **Activez le Mode Développeur** (bouton en haut à droite)\n3. **Cliquez sur \"Charger l'extension non empaquetée\"**\n4. **Sélectionnez le dossier `chrome-extension`**\n5. ✅ L'extension est installée!\n\n### Méthode 2: Fichier .crx (Si disponible)\n\n1. Téléchargez le fichier `.crx`\n2. Allez à `chrome://extensions`\n3. Glissez-déposez le fichier `.crx`\n4. Confirmez l'installation\n\n## 🚀 Utilisation\n\n1. **Cliquez sur l'icône** 😂 dans la barre d'outils Chrome\n2. **Appuyez sur \"Nouvelle Blague\"** pour charger une blague\n3. **Utilisez les boutons d'action**:\n   - 📋 **Copier** - Copie la blague au presse-papiers\n   - 📤 **Partager** - Partage sur Twitter\n   - 🤍/❤️ **Favoris** - Ajoute/retire des favoris\n\n4. **Explorez les onglets**:\n   - 🏠 **Accueil** - Affiche une blague\n   - ❤️ **Favoris** - Vos blagues sauvegardées\n   - ⚙️ **Paramètres** - Options et réglages\n\n## 🎨 Personnalisation\n\n### Mode Sombre\n- Allez à l'onglet **Paramètres**\n- Activez **\"Mode sombre\"**\n- L'extension passe en mode sombre\n\n### Notifications\n- Dans **Paramètres**, activez/désactivez les notifications\n- Vous recevrez des alertes lors d'actions importantes\n\n### Réinitialiser\n- Cliquez sur **\"Réinitialiser les paramètres\"** pour revenir aux valeurs par défaut\n\n## 📁 Structure des Fichiers\n\n```\nchrome-extension/\n├── manifest.json          # Configuration de l'extension\n├── popup.html            # Interface du popup\n├── popup.css             # Styles CSS\n├── popup.js              # Logique du popup\n├── background.js         # Service worker\n├── images/               # Icônes de l'extension\n│   ├── icon16.png\n│   ├── icon48.png\n│   └── icon128.png\n└── README.md            # Documentation\n```\n\n## 🔧 Technologies Utilisées\n\n- **Manifest V3** - Dernière version de Chrome Extensions API\n- **Chrome Storage API** - Pour sauvegarder les favoris\n- **Official Joke API** - Source des blagues\n- **Vanilla JavaScript** - Pas de dépendances externes\n\n## 💾 Stockage de Données\n\n- **Favoris**: Stockés localement avec `chrome.storage.local`\n- **Paramètres**: Stockés avec `chrome.storage.sync` (synchronisés via Google Account)\n- **Aucun** tracage ou envoi de données à des serveurs tiers\n\n## 🐛 Dépannage\n\n### L'extension ne s'installe pas\n- Vérifiez que Chrome est à jour\n- Vérifiez que le dossier contient le fichier `manifest.json`\n- Essayez de recharger l'extension\n\n### Les blagues ne se chargent pas\n- Vérifiez votre connexion Internet\n- Vérifiez que l'API est accessible: https://official-joke-api.appspot.com/random\n- Rechargez l'extension\n\n### Les favoris ne se sauvegardent pas\n- Vérifiez que Chrome autorise le stockage local\n- Videz le cache de Chrome\n- Réinstallez l'extension\n\n## 📝 Licence\n\nCe projet est sous licence **Apache License 2.0**\n\n## 👨‍💻 Auteur\n\n**Bara Abdelaziz** -
